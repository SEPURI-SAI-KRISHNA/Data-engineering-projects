# Security Policy

## Scope

This repository contains **educational and portfolio projects**. None of the projects are deployed as production services by the maintainer. The security policy below applies to the code and configuration files in this repository.

## Supported versions

All projects in this repository are maintained on the `main` branch. There are no versioned releases at this time.

## Reporting a vulnerability

If you discover a security vulnerability — for example, a dependency with a known CVE, a hard-coded credential accidentally committed, or a logic flaw that could be exploited if someone deployed the code — please **do not open a public GitHub issue**.

Instead, report it privately:

1. Use [GitHub's private vulnerability reporting](https://github.com/SEPURI-SAI-KRISHNA/Data-engineering-projects/security/advisories/new) (preferred).
2. Or send an email to the maintainer. The address is in the GitHub profile.

Please include:
- Which project and file(s) are affected.
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept if applicable.

## Response

The maintainer will acknowledge the report within **5 business days** and aim to publish a fix or mitigation within **30 days**, depending on severity and complexity.

## Disclosure

Coordinated disclosure is appreciated. Please allow reasonable time to address the issue before publishing details publicly.
